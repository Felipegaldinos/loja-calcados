# Loja de Calçados

Interface de loja em React com catálogo, carrinho, favoritos e visualização rápida de produtos.

## Recursos

Rotas de início, catálogo, sobre e contato; hooks de carrinho e favoritos com persistência local.

## Tecnologias

React, JavaScript e Vite. Consulte package.json para as dependências e versões declaradas.

## Executar localmente

Use Node.js e npm compatíveis com as dependências declaradas:

```sh
git clone https://github.com/Felipegaldinos/loja-calcados.git
cd loja-calcados
npm install
npm run dev
```

Abra o endereço exibido no terminal. `npm run build` gera a versão de produção. `npm run preview` permite visualizar esse build.

## Onde começar no código

- `src/App.jsx` — ponto de entrada para entender o projeto.

## Estado atual

Persistência no navegador não equivale a pedido confirmado em um servidor. Verifique contatos, produtos e fluxo de compra antes de usar a loja com clientes.
